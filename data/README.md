# data

* all files following the pattern `\d+\_\w+\_\w+\.csv` contain lightcurve data
    * besides the `_ogle.csv` files these are all **SIMULATIONS**!
* [autoencoder_hypsearch.ipynb](./auto_encoder_hypsearch.ipynb)
    * script used to generate [autoencoder_hypsearch.csv](./autoencoder_hypsearch.csv)
* [autoencoder_hypsearch.csv](./autoencoder_hypsearch.csv)
    * training report for training of an autoencoder
* [passbands_specs.csv](./passband_specs.csv)
    * contains specifications for different photometric bands used for the demos and tutorials in this project
    * for consistent plotting


## [fink_lsst_alerts](./fink_lsst_alerts/)
* real Rubin alerts from the [FINK](https://fink-broker.org) broker
* the filename is the Rubin object ID

## [lcs_des](./lcs_des/)
* supernova lightcurves from DES (real data)

## [Pessi2023_SN2017cfo_spectra](./Pessi2023_SN2017cfo_spectra/)
* spectra from the supernova SN2017cfo as presented in [Pessi et al. (2023)](https://ui.adsabs.harvard.edu/abs/2023MNRAS.523.5315P/abstract)
* downloaded from [WISeREP](https://wiserep.org)

## [pulsar_data](./pulsar_data/)
* data from different pulsars
